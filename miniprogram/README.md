# 微信小程序工程（M2实现中）

这是原生 TypeScript 工程，不是已发布或已经真机验收的小程序。当前 AppID 和 HTTPS API 地址为空，所有联网动作在配置缺失时明确停止，不连接仍未迁移的 huayuan.ink，也不使用游客OpenID冒充用户。

已写入四个主入口：创作、素材、作品、我的。账号密码登录与网页共用M2个人空间；访问令牌只放内存，可选将7天刷新令牌保存在本机小程序存储中，不承诺客户端存储加密。API只连接明确配置的第一方HTTPS地址，平台Bearer不附加到OSS视频访问、下载等第三方请求。

## 准备与配置

1. 在此目录安装锁定的开发依赖。已核对官方 `wechat-miniprogram/api-typings` 对应 npm `miniprogram-api-typings@5.2.3` 和 TypeScript `7.0.2` 的注册表元数据；依赖安装不代表编译或真机检查通过。
2. 用户提供真实AppID后填写 project.config.json（AppID本身不是AppSecret），以微信开发者工具导入此目录。不能把AppSecret、服务器私钥或供应商凭据放进工程，即使文件被Git忽略也不应进入客户端。
3. 只有在新的HTTPS账号服务、域名归属迁移及微信合法域名配置实际就绪后，填写 src/config.ts 的 apiBase，例如确认后的 `https://huayuan.ink/api/v1`。当前保持空值。OSS下载/上传域名要分别在微信后台按实际用途配置。
4. 用户后续允许继续其他工作并自动测试，当前`npm run typecheck`已通过；微信开发者工具被占用，按用户指示等待通知后再编译和进行iOS/Android流程。未生成或上传发布包，未触及微信服务协议或账号发布权限。

签名视频地址仅存在页面内存中，页面隐藏时清除，重新进入通过正常API领取；不持久化短期OSS令牌。下载及相册权限只在用户点“保存到相册”后调用平台流程，失败不宣称保存成功。刷新播放授权不会重新执行收费渲染。

素材上传凭据/URL/文件路径也不写wx存储。恢复依靠服务器持久化意图，用户可核验成功上传或重新选择原文件并对比指纹。当前OSS使用POST表单直传；服务端若返回仅PUT授权，小程序明确停止，不把不支持的传输当成功。平台账号令牌只用于第一方业务API。素材标签操作使用POST版本化入口（wx.request不支持PATCH）。

模板剪辑的本地草稿与提交元数据按账号/空间/项目隔离，不含源快照、短期授权或平台凭据。409后保留原输入，载入新版再由用户重新应用；网络结果未知时先查原请求，再沿用原键。隐藏页面停止轮询并丢弃迟到UI更新，不承诺后台执行完成。

片段基础批次新增横向轨道片段条、精确源起止、分割偏移、前移/后移、删除顺接和原声音量输入。操作写入同一不可变编辑版本；裁切/分割按整数帧，不能改变锁定镜头或使其他轨道越界。未保存的裁切、分割或音量输入分组保留，切换动作需先保存或放弃。该段记录片段基础批次；后续字幕及多轨源码进展见下文。实际微信工具/真机及新增媒体输出仍未验收。

后续字幕批次已接入：已有ASR导入（不新识别）、逐句原文/修订对照、时间方式/字号/颜色/位置、文字样式示意、原文每页50条、字幕列表分批50条、SRT/VTT导出。随源字幕可跟随连续分割和裁切；固定时间与不连续关联明确处理，不能悄悄猜测词级对齐。大项目数据量/分页和性能仍需阶段验收，不据服务端10000片段上限宣称手机已完成性能检查。

字幕冲突保留原始文字和参数；若原句已被他页删除，必须明确转为新增草稿后再保存。导出核对revision、timeline_hash和UTF-8内容SHA-256后，使用wx文件接口写入用户目录；仅点击“选择字幕文件接收位置”才调用平台文件分享流程，不自动发送给联系人。模拟wx写入/哈希拒绝检查通过，实际平台保存/分享、字体与媒体烧录/音画同步仍待用户允许微信测试后验收。文本文件只含文字和时间，编辑样式保存在时间线版本中。
