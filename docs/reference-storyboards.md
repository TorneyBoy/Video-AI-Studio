# 参考范围与分镜工作台

这是 M3 / E01、E02 的第一批实现，不是 M3 完成验收。网页左侧“参考创作”和小程序创作首页“参考创作与分镜”使用同一套接口、版本和锁定规则。小程序可独立编辑全部字段；构图、运镜、光影和风格按需展开。

## 当前实现

先通过素材页上传或登记已授权视频，再明确填写参考起止和来源备注。保存范围只读取已有分析，不提交新的分析或生成任务。已有可信切点按所选范围取交集；未覆盖区间保留为待确认范围。显示切点置信度、转写文字和服务来源，不补造语义。超出已知时长拒绝请求，时长未知时显示待核实；没有匹配当前对象的 `media-analysis/2` 时仍可手工策划。冻结证据不会随素材分析更新而变化。

可按参考区间或手工建立分镜，添加、删除和排序镜头；编辑意图、主体、动作、场景、构图、运镜、光影、风格、不可改变细节、旁白、屏幕文字及声音/音乐位置。参考字幕不会自动进入旁白或当前商品事实。事实有独立核对/锁定状态，镜头可锁定完整内容。总时长须等于各镜头之和；确认前补齐镜头意图、主体并核对所填事实。确认分镜不代表生成、渲染、质量审核或交付已完成。

保存产生不可变版本，过期基线返回冲突。历史只读，可沿用为新草稿；保存仍需检查当前版本和锁定内容。修改或删除锁定内容须明确提供解锁 ID。重放返回原操作对应的版本，并附当前 `head_revision_id`；双端不会用旧回执覆盖新的本机输入。

参考素材首次登记默认仅供分析。只有用户明确允许画面用于成片，才允许进入新的自动计划、计划报价、批次分析报价和新增编辑素材候选。无显式素材列表的自动计划排除仅供参考的视频；Worker 编译前再次检查，防止排队期间用途变更被忽略。原已保存时间线、分镜及冻结来源不回写。

播放器通过存储网关为同租户对象签发最多300秒的地址，不写入版本、缓存或回执，且受对象路径/公共域名限制。源对象身份变化后拒绝播放和用途修改，需重新登记。第三方 URI 是否可播放取决于网关实际支持；当前网关仅支持受管 OSS。本机浏览器样本没有真实媒体，不作为云播放验收。

## 数据与接口

`0022_storyboard_authoring` 只新增 `reference_usage`、`reference_analyses`、`storyboard_documents`、`storyboard_revisions`，不为旧素材自动添加用途，不发起媒体请求，不改写旧任务或费用。

以下接口统一使用 `/api/v1` 前缀：

| 接口 | 功能 |
| --- | --- |
| `GET/POST /projects/{id}/references` | 分页摘要 / 保存范围和已有证据 |
| `GET /references/{id}` | 冻结详情、对象是否一致、当前用途 |
| `POST /references/{id}/usage` | 明确设置 `allow_output` |
| `POST /references/{id}/access` | 临时参考播放地址 |
| `GET/POST /projects/{id}/storyboards` | 分页摘要 / 新建分镜 |
| `GET /storyboards/{id}` | 当前完整版本 |
| `GET/POST /storyboards/{id}/revisions` | 分页历史 / 以基线新增版本 |
| `GET /projects/{id}/reference-requests/{key}` | 查询原参考保存 |
| `GET /projects/{id}/storyboard-requests/{key}` | 查询原分镜创建 |
| `GET /storyboards/{id}/requests/{key}` | 查询原版本保存 |

创建参考、新建分镜和保存版本带 `Idempotency-Key`；相同内容同键返回原结果，异内容同键冲突。未知结果缓存原路径、原键和原请求体，冻结新提交；先查回执，未查到时由用户重发完全相同的请求。缓存按账号/项目隔离，页面隐藏或上下文变化后忽略迟到页面更新。非法时长保留输入并拦截保存。跨端表单规则源 `web/storyboard-form.js` 与 `miniprogram/src/vendor/storyboard-form.js` 保持逐字一致。

限制：参考终点最多2小时、最多500个证据区间；分镜1–500镜头、最多100条事实，单镜头0.1–120秒、总时长最多2小时。时间最多三位小数，服务端使用整数毫秒且拒绝布尔值。证据/版本快照最多2MiB；超限明确拒绝，不截断。列表返回分页摘要，详情/历史另读。

## 未完成的集成

现有阿里云托管分析提供切点和 ASR，尚无所需主体/场景语义、风格和关键帧语义。界面明确显示不可用；已有切点不等于完整参考分析。智能编导的纯数据 schema、锁定及新事实确认校验已建立，尚无实际多模态 Provider、报价和异步编导作业；后续必须复用能力目录、报价、预算预占和远端恢复，不能直接在本 API 发起付费调用。

E03已进一步接入共用筛选条件、用户内容标注、可解释候选、来源采用版本及补拍清单，详见[镜头匹配](shot-matching.md)；没有合适素材保留缺口。下一步编译已采用素材到Timeline，E04再接单镜头报价与生成候选。本批分镜尚不能直接渲染，手工方案不能替代真实智能分析/编导验收。
