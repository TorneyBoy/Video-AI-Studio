# M2 双端素材工作台

本项为实现中的C05，不是微信真机或生产交付完成报告。当前检查与具体范围见[m2-current-checks.md](m2-current-checks.md)。

| 子内容 | 实现方法 | 能达到的效果 | 网页/小程序呈现 |
| --- | --- | --- | --- |
| 选择与拍摄 | 网页File输入；原生chooseMedia相册/拍摄与chooseMessageFile聊天文件；检查服务端文件大小配置 | 手机可直接选取视频、图片，聊天文件可包含音频；不依赖电脑代传 | 网页“选择文件”；小程序“相册/拍摄”“聊天文件/音频” |
| 文件指纹 | 网页使用固定版本MIT库，以1MiB切片更新SHA-256；小程序优先平台SHA-256，不可用时通过文件系统1MiB分块降级 | 不把整个大文件载入JS内存；重新选择文件时能区分原文件与替代文件；这不是媒体分析 | 明确的指纹计算阶段，传输阶段才显示实际上传进度 |
| 真实直传 | 控制面只创建持久化意图/续签；浏览器XHR、原生wx.uploadFile直接POST OSS；平台Bearer不附给OSS | 文件不经过API控制面；短期签名仅在本次调用内存中使用 | 单文件上传记录、实际进度、独立错误提示 |
| 重复与恢复 | 以项目+内容哈希查找现存意图，保留原键/原规格；先核验对象，只有明确不存在才传输；过期续签同一意图 | 丢失上传确认后可核验恢复；同项目相同内容不重复建素材；不以新文件覆盖原对象 | “核验已有上传”“重新选择原文件”；退出小程序后不承诺继续后台上传 |
| 检索与选择 | 服务端tenant/project过滤，名称字面包含检索、独立规范化标签索引、媒体类型过滤；选择集合与筛选结果分离 | 跨筛选保留同项目选择，切账号/项目隔离；百分号等不作为通配符扩大搜索 | 名称/标签/类型筛选、已选数量；小程序50条分页，网页完整分页仍待补齐 |
| 单项整理 | 只允许展示名称、user_tags、user_note，携带user_labels_revision；服务端行锁重读后写入 | 不改变URI、哈希、许可或分析证据；其他页面更新后返回409，旧表单不覆盖新内容 | 页内表单；冲突提示、保留输入、禁止再次直接保存，要求重新打开审阅 |
| 批量整理 | 两端对打开时捕获的素材快照逐项追加标签；保留各项旧标签和备注 | 一个项目失败不冒充全部成功；成功数与各项错误可见 | 批量追加标签表单；单项重开后处理冲突，不自动刷新版本强行覆盖 |
| 分析衔接 | 上传后可选创建视频分析，复用稳定的asset-analyze键；计划请求复用已有对应源的分析Job | 上传成功与分析开始分别表达；预算阻止分析不抹去上传成功；失败/未知分析先恢复原任务 | “已上传，分析任务已创建”或“已上传；分析尚未开始”的原因提示 |

标签动作使用相同业务处理函数的POST/PATCH入口；wx.request不支持PATCH，原生使用POST。请求身份仍由正常会话决定，不接受客户端Tenant头替代身份。

新增依赖为`js-sha256@1.0.0`，源包分发内容通过`scripts/bundle-client-deps.cjs`复制到两个客户端；锁文件、许可证与SHA收据位于package-lock.json及third_party/。这项依赖只用于文件指纹，不替代服务端真实对象哈希核验。

尚未完成：微信真实选择/拍摄/上传/退出恢复，原生实际SDK兼容性与合法域名，素材缩略图/分析详情与手动恢复入口的完整交互，以及个人用户可直接操作的已有对象导入。既有register-remote仍需存储网关证明，不能把只输入URI称为生产可用导入。图片、独立音轨等上传与最终渲染是不同能力，后者仍须在C08/C09完成真实验收。C06锁定/替换/局部重算、不可变编辑版本与批量任务仍按完整Goal继续。
